# Security

Please do not open a public issue for a security problem. Email
support@websitescreenshotworld.com with "Security" in the subject, what you found and how to reproduce it. We
answer within two working days and credit you in the release notes if you would like.

Never put an API key or a webhook secret in an issue, a pull request or a test. The keys in `spec/fixtures/keys.json`
are made up and do not work.
